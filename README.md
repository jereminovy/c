# Auto Repair Miner (Fabric 1.21.4)

Prosty mod client-side do Minecraft 1.21.4, który:
- po wciśnięciu **K** włącza/wyłącza auto-kopanie,
- podczas działania stale przytrzymuje **lewy** i **prawy** przycisk myszy,
- co 5 minut wysyła komendę `/repair` na czacie.

## Wymagania
- Java 21
- Minecraft 1.21.4
- Fabric Loader
- Fabric API

## Uruchomienie
```bash
gradle runClient
```

## Sterowanie
- **K** — włącza/wyłącza auto-kopanie.

Po wejściu do świata mod jest gotowy, ale zaczyna działać dopiero po kliknięciu **K**.

## Uwaga
Automatyzacja może być niezgodna z regulaminem części serwerów. Używasz na własną odpowiedzialność.
